# My Homelab

This repository documents the setup and development of my personal IT homelab.

## Goals

The purpose of this homelab is to gain practical experience with:

- Networking
- Linux administration
- Virtualization
- Windows Server and Active Directory
- IT security
- Docker and containers
- Automation
- Cloud technologies

## Hardware

### Server

- Lenovo ThinkCentre M920q Tiny
- Intel Core i5-8500T
- 16 GB RAM
- 512 GB SSD

## Virtualization

The homelab is based on Proxmox VE.
